# pixel mandala

A 9:16 pixel temple of waterfalls and water-driven machines. Every stream is
traced through the scene each frame, so the water re-routes as the diamonds,
wheels, seesaw and buckets it turns move. Drag a part to turn it by hand;
space pauses.

**Live:** https://zscore.github.io/pixel-mandala/cascade.html

`editor.html` is an editable version: the panel on the right adds parts
(springs, ledges, diamonds, wheels, sōzu, …) and edits the selected one; drag
parts around the scene and the water re-routes live. Scenes save in the browser
and export/import as JSON. `?fresh` starts from the original temple.

`index.html` is the earlier, static mandala.
